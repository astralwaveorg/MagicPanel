生成时间：2026-10-21 · 对应版本：`b325c55` 之后的全部功能（含 WebDAV 备份、分页、批量操作、产物配置可编辑、安卓客户端）

## 一、项目结构

```
MagicPanel/
├── server/                 FastAPI 后端
│   ├── app/
│   │   ├── main.py         应用入口、CSP/HSTS、静态资源、后台任务（留存清理、WebDAV 定时备份）
│   │   ├── config.py       全局常量（引擎、平台、规则类型、空组保护等）
│   │   ├── db.py           SQLite 封装：事务、只读连接、迁移、分页、排序子集
│   │   ├── security.py     口令散列（PBKDF2 600000 轮）、主密钥 Fernet、审计
│   │   ├── deps.py         当前维护者、会话校验、CSRF
│   │   ├── routers/        19 个路由模块（见下表）
│   │   ├── compiler/       渲染（render.py）、校验（validate.py）、快照与差异（base_config.py）
│   │   └── services/       抓取、测速、构建、调度、留存、WebDAV 备份、本地单节点等
│   └── tests/              100 条 pytest 用例
├── src/                    Vue 3 + Element Plus 前端（15 个页面 + 7 个组件）
├── android/                安卓客户端（Kotlin + WebView），产出已签名 APK
├── scripts/                部署、备份、巡检、生产配置脚本
└── docs/                   开发规格、产物构成、审查记录
```

## 三、安卓客户端

### 为什么是 WebView 壳

管理端本身是 Web 应用（Vue 3 + Element Plus），全部逻辑在服务端。客户端用 WebView 承载，
**不重写第二套业务逻辑**——登录、CSRF、批量操作、上传下载、审计都走同一套接口，
浏览器里能做的，App 里都能做，且不会出现"两边行为不一致"。

### 已实现能力

| 能力 | 说明 |
|---|---|
| 登录态持久化 | `CookieManager` 持久化会话，登录一次长期有效（已验证：覆盖安装后仍保持登录） |
| 文件上传 | `WebChromeClient.onShowFileChooser` → 系统选择器（"本地上传"核心文件可用） |
| 下载 | `DownloadListener` → 系统 DownloadManager，存到"下载"目录 |
| 站内/站外分流 | 同域名留在 App 内，其它交给系统浏览器 |
| 返回键 | 站内优先后退，无历史才退出 |
| 下拉刷新 | SwipeRefreshLayout |
| 面板地址可改 | 「⋮ → 面板地址」，改完立即生效，不必重新打包 |
| 重新登录 | 「⋮ → 重新登录」清 Cookie 并回到登录页 |
| 深色主题 | 与面板一致的深色外观，状态栏/手势条内边距适配 |
| 悬浮小房子 | 右下角悬浮按钮，点击回门户首页（`/`）；可拖到任意位置，松开自动吸附到左/右边缘，位置本地记住；拖动时半透明缩小，不遮挡内容 |
| 刷新 | 工具栏常驻刷新按钮；**不使用下拉刷新**（下拉手势会劫持 WebView 的向下滑动，导致手指往下划总是触发刷新） |
| Android 15+ | 强制 edge-to-edge 已适配（`WindowCompat.setDecorFitsSystemWindows(false)` + `WindowInsetsCompat`） |
| 网络安全 | `usesCleartextTraffic=false`，只允许 HTTPS |

### 适配机型

- minSdk 24（Android 7.0） / targetSdk 35（Android 15）
- 已用 Android 15（API 35, arm64-v8a）模拟器实测：安装 → 启动 → 登录 → 概览/设备/审计页面全部正常
- 小米 17 Pro Max、一加 13 均为 Android 15/16 机型，接口与特性完全覆盖；厂商 ROM 的差异点（edge-to-edge、后台限制）已按通用方案处理

### 安装

```bash
# 直接安装（手机需开启"允许安装未知来源应用"）
adb install -r dist/MagicPanel-1.0.0.apk
```

或把 APK 传到手机后点击安装。首次打开如提示"未知来源"，按提示允许即可。

### 本轮修复的缺陷

| 缺陷 | 修复 |
|---|---|
| 恢复备份后会话被级联删除，管理员被登出 | 恢复范围含 `sessions` |
| 同一秒内连续备份互相覆盖 | 快照文件名带去重后缀 |
| MATCH 兜底排在中间时，其后的规则永不生效 | 渲染时自动把兜底提到末尾 + 产物校验拦截 + 生产数据重排 |
| 空组保护占位排在首位，可能被客户端选为首选 | 改排到自动组末尾 |
| 批量改"包含策略"可造成自引用 | 剔除指向自己的引用 |
| 设备排序列全为 0，拖拽"排了不生效" | 加列时按 id 初始化 |
| PIN 规则前后端不一致（提示 6 位、报错 4 位、实际 6 位） | 统一 4 位；后端中文提示；前端去掉 "Value error, " 前缀；历史 6 位 PIN 仍可继续使用 |
| 可用率只有红/绿两色 | 每 10% 一档，红→橙→黄→绿渐变，30% 以上明显转向绿色 |
