# MagicPanel 接口清单与安卓客户端说明

本文说明旧版接口和 Android 客户端。路由发生变化时，运行 `scripts/gen_api_docs.py` 更新接口清单。

---

## 一、项目结构

```
MagicPanel/
├── server/                 FastAPI 后端
│   ├── app/
│   │   ├── main.py         应用入口、CSP/HSTS、静态资源、后台任务（留存清理、WebDAV 定时备份）
│   │   ├── config.py       全局常量（引擎、平台、规则类型、空组保护等）
│   │   ├── db.py           SQLite 封装：事务、只读连接、迁移、分页、排序子集
│   │   ├── security.py     口令散列（PBKDF2 600000 轮）、主密钥 Fernet、审计
│   │   ├── deps.py         当前维护者、会话校验、CSRF
│   │   ├── routers/        19 个路由模块（见下表）
│   │   ├── compiler/       渲染（render.py）、校验（validate.py）、快照与差异（base_config.py）
│   │   └── services/       抓取、测速、构建、调度、留存、WebDAV 备份、本地单节点等
│   └── tests/              120 条 pytest 用例
├── src/                    Vue 3 + Element Plus 前端（15 个页面 + 7 个组件）
├── android/                安卓客户端（Kotlin + WebView），产出已签名 APK
├── scripts/                部署、备份、巡检、生产配置脚本
└── docs/                   开发规格、产物构成、审查记录
```

## 二、接口总览

> 完整清单由 `scripts/gen_api_docs.py` 从路由定义自动生成（文末「自动生成的接口清单」段，含每个接口的路径、方法与首行说明）；`--check` 模式供 CI 校验清单是否过期。（历史上手维护的 96/120/122 数字互相矛盾，2026-11-18 起以脚本生成。）

> **发布模型已切换为单一版本生命周期状态机**（`builds.status` = `BUILT` / `TESTING` / `PRODUCTION` / `OFFLINE`），「稳定 / 候选通道」概念已废弃。相关接口与字段变化见 §5；`GET /api/v1/overview` 与 `POST /api/v1/portal/data` 的顶层由 `channels` 改为 `release_state`，设备项由 `channel` 改为 `env`。

## 三、安卓客户端

Android 管理客户端使用 WebView 承载同一套管理界面，认证与写操作仍走服务端 Cookie 和 CSRF 校验。它是管理入口，不能据此推断代理客户端的协议、分流或自动化能力。

上传、下载、站外链接、返回键、地址切换与刷新行为以 `android/` 实现为准；SDK、版本与包名以 Gradle 和 Manifest 为准。使用 HTTPS 面板地址，文件下载还需验证目标 Android 版本的系统权限与下载行为。

构建和安装后，在测试环境验证登录、页面导航、文件选择、下载及覆盖安装。模拟器结果不能代替厂商 ROM 和真机验收。

### 签名与安装

签名密钥由部署方在仓库外保管，应在构建时使用部署方的私有口令。不要把 keystore、口令、私有备份路径或发布账号写入文档。覆盖安装要求签名与已安装应用一致；更换签名会影响升级与用户数据保留。

将构建生成的 APK 安装到测试设备，可使用 `adb install -r <apk-path>`。安装前核对包名、版本、签名和目标设备。
