# 旧版维护者交接

服务端使用 FastAPI 和 SQLite；前端为 Vue。门户位于 `/`，管理端位于 `/admin`。应用负责分发订阅，路由器和客户端是配置的使用者。服务端容器内的回环地址始终指向该容器。

| 任务 | 从哪里开始 |
| --- | --- |
| 确认实际页面和操作 | [使用文档](../使用文档.md) |
| 修改服务端、前端或数据库迁移 | [开发文档](../开发文档.md) |
| 调整基础配置、引擎平台、设备例外与拓展 | [配置文档](../配置文档.md) |
| 变更规则顺序、组引用或多方案行为 | [多套分流方案](方案设计-多套分流方案.md)、[产物构成](../development/MagicPanel-构建与发布-产物构成.md) |
| 安装与部署 | [1Panel 与 Docker](../deployment/1Panel-Docker-部署.md) |

**改配置时**，先确认方案、设备和引擎，再优先使用经过校验的业务接口。设备层只存相对上层的差异；`["*"]` 表示所有适用对象，`[]` 表示无适用对象。改规则前核对顺序、成员引用及兜底目标；变更后核对目标引擎的最终产物，不以面板保存成功代替设备验证。

**交接时**记录目标、改动、已验证项和未验证项。仓库指令不存储站点身份、凭据、设备清单、当前线路优先级或线上操作授权。实际部署的交接文件与备份由该部署的维护者保管。
