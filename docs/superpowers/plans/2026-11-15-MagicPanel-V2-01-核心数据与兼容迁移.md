# MagicPanel V2 核心数据与兼容迁移 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立可恢复、无普通接口凭据泄漏、身份和引用稳定、配置解析唯一、能够供检测/选路/界面/发布直接消费的 M0/M1 数据底座。

**Architecture:** 保留 FastAPI、SQLite 与现有路由；把备份、身份、引用、权限、配置解析分别收敛到小型服务模块。连接材料使用加密 SQLite BLOB，与版本引用在同一个事务提交；旧 URL 成为集中适配器。runtime_profile 选择既有三层的受控基线，不增加第四份 YAML 覆盖。

**Tech Stack:** Python 3.11+、FastAPI/Pydantic、SQLite WAL、cryptography、PyYAML、pytest；Vue 3 的完整 UI 迁移由 03 计划负责。

**Spec:** [总体设计与审查稿](../specs/2026-11-15-MagicPanel-V2-总体设计与审查稿.md)、[工程检测与验收规范](../specs/2026-11-15-MagicPanel-V2-工程检测与验收规范.md)。执行前读 `AGENTS.md`、`docs/reference/Agent-交接提示词.md`、`docs/开发文档.md`、`docs/配置文档.md`。

### 0.3 HTTP 合同

| API | 固定合同 |
| --- | --- |
| `GET /api/v1/nodes?limit=50&offset=0` | `{items,total,limit,offset,catalog_revision}`；limit1..200，offset≥0；ordinal排序，不随排名抖动 |
| `GET /api/v1/nodes/{node_uid}` | 安全详情、meta、public_params、configured_secret_fields、引用和版本 |
| `PATCH /api/v1/nodes/{node_uid}/metadata` | expected_catalog_revision、display_name（可省略）、meta人工patch（首版labels/note/claimed_country）；仅edit；不可写observations/已验证国家/连接材料 |
| `PATCH /api/v1/nodes/{node_uid}/configuration` | expected_revision、protocol/server/port/public_params、secret_set、secret_clear、extra_yaml_set/clear_extra_yaml；省略保留；edit+reveal；过期409 |
| `POST /api/v1/nodes/{node_uid}/reveal` | reveal能力+CSRF+审计+no-store；仅显式请求回明文 |
| `POST /api/v1/nodes/rename-preview` | node_uids、names:{uid:desired_emit_name}、expected_catalog_revision；返回preview_id/差异/冲突/引用 |
| `POST /api/v1/nodes/rename-apply` | preview_id、expected_catalog_revision；一次有效，无网络/构建/发布 |

错误为 `{detail:{code,message,request_id,fields,references,expected_revision,current_revision}}`；request_id为必需安全关联ID，其余后四项按适用情况省略，不能放秘密context；fields仅安全ID/字段路径。沿用00的壳，保留现有ApiError.detail。固定code：stale_revision、reference_ambiguous、group_cross_variant、catalog_material_invalid、backup_missing_variants、backup_missing_resource、key_required、migration_incomplete、preview_invalid、preview_expired、preview_actor_mismatch、preview_consumed。
