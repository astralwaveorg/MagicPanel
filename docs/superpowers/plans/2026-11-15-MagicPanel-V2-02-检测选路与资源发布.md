# MagicPanel V2 检测、选路与资源发布 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按auto_stable_v1实现周评估、地区日检和当前路径哨兵驱动的有界恢复建议，生成AI无成本与Google严格美新日计划，编译受管恢复产物，并保住国内独立通路及可恢复的整包发布。

**Architecture:** 保留 FastAPI/SQLite/Vue 与现有全局测试/生产状态机。01 提供节点稳定身份和权限；本计划建立持久任务、独立 observer、有限 adapter、纯 planner、语义编译和不可变分发资源；03 消费安全 DTO。路由器应用、家庭网络改动和控制器写入全部留到总计划末期，本计划提前验收只使用离线 fixture 或独立 VPS observer，不把 NAS 透明代理后的拨测冒充家庭直拨证据。

**Tech Stack:** Python 3.11+、FastAPI、SQLite WAL、Pydantic、httpx、PyYAML、cryptography、pytest；复用现有依赖，不新增 Redis、消息队列服务或 DNS 产品。

**Spec:** [自动恢复与检测策略](../../reference/自动恢复与检测策略.md)是`auto_stable_v1`节奏/预算/阈值的唯一数字合同，优先旧稿默认值；再读[总体设计](../specs/2026-11-15-MagicPanel-V2-总体设计与审查稿.md)、[工程规范](../specs/2026-11-15-MagicPanel-V2-工程检测与验收规范.md)、[开源研究](../../reference/2026-11-15-MagicPanel-V2-开源与检测研究.md)、本地个人环境[生产迁移草案](../../network/2026-11-15-MagicPanel-V2-生产迁移草案.md)。本轮不运行开发/提交命令。

## Global Constraints

- [稳定性与覆盖验收补充](../specs/2026-11-15-MagicPanel-V2-稳定性与覆盖验收补充.md)是本计划必读验收合同；Task9负责最终业务语料，Task11负责规则内容/时效，Task13统一消费门禁，不能只做Google样例和YAML结构检查。
- 最终模式是`auto_stable_v1`：每周全量、地区日检、当前路径300秒哨兵、可信故障确认后有界复核备用并自动切换；准确范围/数字/Google回升全部引用共同策略§1–6。实施/灰度前生产自动化仍关闭，04验收后启用；不再以record_only/weekly_manual作为完成默认，自动整包生产发布单独默认off。
- 所有已授权且协议适配目标的来源/本地节点进入周批次；机场可以胜过自建；不按来源类别加质量分。
- AI 排名完全不使用价格、成本、免费额度或计费倍率，包括平局；人工授权和供应商硬停机是准入状态，不能伪装成费用评分。
- 其他海外 AI 共一个通用前台策略；Gemini 保留后台矩阵，实际复用 Google 档位路径，不另建 Gemini 前台组。
- Google 全业务按实际目的出口美国→新加坡→日本严格档位；任一合格美国候选可用就留美国，完整美国候选均证实失效才进新加坡，再同理进日本。unknown/限流/probe坏/预算跳过/小池主备失效不证明整档耗尽；普通策略无DIRECT，网关基础联网故障另审，不新增全模式独立Google阻断。普通健康推荐非Google，Google专项覆盖各档候选，非US访问本身不禁止。
- 住宅当前不存在，未授权时 0 请求/0 字节；默认排除吞吐、通配来源、MATCH、客户端 url-test/provider health-check；面板只硬控自身探测预算，真实业务配额依赖供应商/受控网关。
- 保留三层基础配置名称、结构键保护、引擎平台唯一、设备列表追加语义；不新增第四份任意 YAML 覆盖层，不改用户已有 `sort` 或相对顺序。
- HTTP 200/401、GeoIP/ASN、节点名称、入口 IP 不证明账号/播放能力或 Google 目的出口；任务错误、unknown、challenge、限流不写成节点永久失败。
- 全局保留一个 TESTING、一个 PRODUCTION；新方案失败仍阻断整包；单 SQLite 事务只承诺本地指针原子性，不承诺跨 AGH/路由器/设备分布式原子应用。
- 自动化测试默认禁真实外网；独立VPS observer仅在另行明确授权后接预置白名单与签名观测，不继承家庭资格；本计划不安排部署/SSH/路由器配置命令。
- 代码完成后执行本地测试和前端构建；实际部署、生产故障注入及路由器写入由总计划末期独立门禁控制。本计划中的 commit 命令仅在后续实施阶段执行。
- 全部代理节点/core失效或变慢都不阻塞大陆DNS/bootstrap/DIRECT数据路径；探测队列、控制器和NAS故障不加入国内请求关键链。核心整体失效由04独立守护进入BASIC_WAN、海外允许原生尝试并告警；单业务或全部节点失败不冒充核心失败。

def round_robin(buckets):
    ordered=[]
    queues={k:list(v) for k,v in sorted(buckets.items())}
    while any(queues.values()):
        for key in queues:
            if queues[key]:
                ordered.append(queues[key].pop(0))
    return ordered

def digest(value):
    import hashlib,json
    blob=json.dumps(value,sort_keys=True,separators=(",",":"),
                    ensure_ascii=False,allow_nan=False).encode("utf-8")
