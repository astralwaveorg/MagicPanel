# MagicPanel V2 用户界面与体验闭环 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让使用者看清业务覆盖、Google 地区档位、检测预算、配置生效与恢复边界，解决现有误报、隐式请求、旧 PIN 输入竞态和作用范围混乱。

```js
import { reactive } from 'vue'
export function createScopedRequest(fetcher) {
  const state = reactive({data:null,loading:false,error:null})
  let seq=0, controller
  async function load(scope) {
    const id=++seq; controller?.abort(); controller=new AbortController()
    state.loading=true; state.error=null
    try { const data=await fetcher(scope,controller.signal); if(id===seq) state.data=data }
    catch(e) { if(id===seq && e.name!=='AbortError') state.error=e }
    finally { if(id===seq) state.loading=false }
  }
  return {state,load,cancel(){++seq;controller?.abort();state.loading=false}}
}
```

export function probeSelection(entries) {
  const seen=new Map()
  for(const e of entries) {
    if(seen.has(e.node_uid)&&seen.get(e.node_uid)!==e.revision) throw new Error('目录版本变化，请重新选择')

  return [...seen].map(([node_uid,revision])=>({node_uid,revision}))
}

- [ ] Step 2：实现`/^(?:\d{4}|\d{6})$/`；HTML pattern相同，去掉onPinInput自动fetch。输入第四位不发请求；按钮/Enter才提交，loading禁重复。401不跳管理员登录，429按服务端Retry-After显示；失败不因旧响应清空后来输入。

```js
import {reactive} from 'vue'
export const validPortalPin=value=>/^(?:\d{4}|\d{6})$/.test(value)
export function createPortalGate(send) {
  const state=reactive({loading:false,error:null,data:null}); let pending=null, seq=0
  return {state,submit(pin) {
    if(!validPortalPin(pin)) return Promise.reject(new Error('请输入4或6位数字'))
    if(pending) return pending
    const id=++seq;state.loading=true
    pending=Promise.resolve().then(()=>send(pin)).then(data=>{if(id===seq)state.data=data;return data})
      .catch(e=>{if(id===seq)state.error=e;throw e})
      .finally(()=>{if(id===seq){state.loading=false;pending=null}})
    return pending
  },reset(){++seq;pending=null;state.loading=false;state.error=null;state.data=null}}
}
```

state已由工厂建立reactive，调用方不再包原始对象；退出时reset；send是门户专用安全fetch，不借管理员401自动跳转。输入更改不自动send，提交时捕获该次PIN，响应不回写或清空后来输入。
