# v2 界面、规则和交付验收 · 2026-11-28

本次只发布 Studio。OmniSub 的镜像、升级和服务切换由其维护者负责。

| 顺序 | 工作 | 验收条件 |
| --- | --- | --- |
| 1 | 逐平台客户端导入 | 从浏览器解析每个 Scheme，再实际下载内层地址；跨引擎、中文名称、运营商、仅节点与不可用配置均有验证。 |
| 2 | 统一页面密度与手机布局 | 一级页面取消重复面包屑；标题、操作、筛选能在窄屏换行；登录、工作区、弹窗、键盘和底部导航均可用。 |
| 3 | 在规则库管理 magic-sets | 能查看 GitHub 当前文件、历史、差异，提交时检查文件版本；同名资源和草稿并发变更不被覆盖。应用到草稿是单独操作。 |
| 4 | 核查不同客户端的产物 | 候选编辑与生效结果分开；按平台和线路查看实际发布的规则和资源，能识别端口、最终规则和不兼容情况，预览不泄露节点密码或订阅密钥。 |
| 5 | 复查主要流程 | 运行后端测试、前端检查、构建和浏览器流程；重点检查跨平台、窄屏、异常、取消和未登录访问。 |
| 6 | 部署及复验 | 推送 v2，只更新 Studio，核对镜像 revision、外网健康、已发布的配置和页面资源。记录未覆盖的真机操作。 |

## 客户端导入依据

每个按钮按目标应用重新构造订阅参数；只有已发布且可用的目标才可导入。浏览器直接调用本机协议，不经过第三方跳转网站。仅节点列表保留复制和二维码。

| 客户端 | 调用与适用范围 |
| --- | --- |
| Clash Verge Rev、FlClash、Clash Nyanpasu、Clash Mi | 分别用 clash-verge、flclash、clash-nyanpasu、clashmi 的 install-config。依据：[Verge](https://github.com/clash-verge-rev/clash-verge-rev/blob/055dbf5d357cf15b70cb542962a0e232c276a6dc/src-tauri/src/utils/resolve/scheme.rs)、[FlClash](https://github.com/chen08209/FlClash/blob/deba70d80d2af509171f9c6465de9d14719f0399/README.md)、[Nyanpasu](https://github.com/libnyanpasu/clash-nyanpasu/blob/1dde81b8bceec9310ec80b2be286312aa286d986/frontend/nyanpasu/src/utils/deep-link.ts)、[Clash Mi](https://github.com/KaringX/clashmi/blob/b4cec63703c3ff736af235fcde0d44fa74b2e160/lib/screens/scheme_handler.dart)。 |
| ClashX.Meta、Clash Party、Clash Meta for Android | 分别用 clashx、mihomo、clashmeta 的 install-config。[ClashX.Meta](https://github.com/MetaCubeX/ClashX.Meta/blob/471b3e04153655374516b8589cacdb6db373d913/ClashX/AppDelegate.swift)、[Party](https://github.com/mihomo-party-org/clash-party/blob/1458f9626ad4b223424260bf083435b26b435d73/src/main/deeplink.ts)、[CMFA](https://github.com/MetaCubeX/ClashMetaForAndroid/blob/6e635124cc72f8c102b7e76d849c384deba28b3f/README.md)。部分协议也会被其他应用注册，最终接收者由系统决定。 |
| Stash | [官方协议](https://stash.wiki/faq/url-schema)要求把订阅地址整体编码后放入 url 参数。Windows 官方安装包 0.1.47-b51 的注册信息包含 stash 协议，主程序含 install-config；另支持 macOS、iOS。Android 未取得注册证据，使用复制；Apple TV 从电视端添加。 |
| Shadowrocket、Surge | iOS 小火箭使用 config/add 地址后缀；[Surge 文档](https://manual.nssurge.com/tools/url-scheme.html)规定三个斜杠，Mac 旧版入口使用 surgeconfig。新旧 Surge 配置分别指定引擎。 |
