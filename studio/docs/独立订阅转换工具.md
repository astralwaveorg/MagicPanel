# 独立订阅转换工具 · 2026-11-28

首页的「订阅」交付已发布的平台模板和运营商策略。「订阅转换」解决另一件事：临时合并订阅或节点，选择输出格式，给客户端一个能更新的地址。两者共享登录和内网转换器，转换工具独立保存自己的数据，不写模板、草稿或发布记录。

## 参考与取舍

核对了 [cmliu 的实现](https://github.com/cmliu/sub-web-modify/blob/81d6603/src/views/Subconverter.vue)、[上游实现](https://github.com/youshandefeiyang/sub-web-modify/blob/71ac757/src/views/Subconverter.vue) 和[示例站](https://sub.cmliussss.net/)。两个项目均在浏览器选后端，把多条来源用竖线合并，再编码 target、url、config 和高级选项。它们也能解析已有长链接，将生成地址交给短链服务。cmliu 的 Surge 4/5 映射到 ver=4，上游的 Surge 5/6 映射到 ver=5；上游另有自定义 UA 和 DNS 选项。不能从按钮标题推断转换器已支持某个内核版本。

新页面、新接口和存储均独立实现。浏览器只向同站提交。继续使用 Compose 内的 SubConverter-Extended；采用[当前部署版本的目标格式](https://github.com/Aethersailor/SubConverter-Extended/wiki/Compatibility)。客户端读取服务器分配的随机地址，路径不含原订阅或节点。无需新增 api 或 sub 域名；将来如需在面板迁移后长期维持独立分发域名，再考虑 sub。

## 页面与实施计划

1. 一级导航新增「订阅转换」。先输入来源和目标，展开后才展示筛选、重命名、输出内容和规则模板。与管理平台模板分开。
2. 允许公开 HTTPS 订阅、节点分享链接及含 proxies 的 YAML。服务器先读取内容；拒绝私网来源、嵌套远程节点提供者及脚本。只向内网容器提交节点材料。
3. 四种主要客户端使用按内核校验的格式。独立工具提供简洁规则模板；需要运营商和完整规则库时使用订阅首页。其他格式交给容器的原生生成器。Shadowrocket 区分配置文件和节点订阅。
4. 保存可撤销的更新地址，支持复制、下载与刷新。来源或后端失败时保留上次可用结果，显示刷新状态。新地址必须先成功转换。不得将错误页、空节点或错误口令当作成功。
5. 用合成节点验证端到端转换和鉴权；用隔离账户走浏览器，再从 v2 分支发布。受支持的选项以页面和服务端白名单为准；不接入公共后端、外部短链、远程执行脚本或任意 INI。旧长链只在本地读取，不访问其原后端。

## 本期可用范围

工具入口为同一站点的 `/tools/converter`。手动选择、自动测速、自定义域名/IP 分流均由本地生成；Mihomo 完整配置还可选 ACL4SSR 公共模板（固定仓库修订）。该模式只用节点名称和合成占位节点编排策略组，真实节点凭据留在本地。规则先在服务端展开，避免配置引用用户设备无法访问的容器内地址。公共模板的外部规则数据仍可能更新；刷新失败不覆盖现有结果。

提供 17 种输出。Mihomo 和 Stash 可取完整配置或仅节点；Surge 6、Surge 5 兼容输出及 Shadowrocket 提供原生配置。Shadowrocket 节点订阅、sing-box、Quantumult X、Loon、Surfboard、混合链接、v2rayN、v2rayNG、SS、Trojan、VLESS 和 Hysteria2 由内网容器输出。可用同一份合成 SS/Trojan/VLESS/Hy2 输入逐项验格式，不代表每种输出都能保留四种协议。单协议订阅会过滤其他协议。

节点名支持 RE2 正则筛选、替换、去重、排序及常见地区旗帜处理；开关只在对应格式出现。二维码在浏览器本地生成。旧长链解析只导入支持的选项，其余逐项提示；不会请求旧后端、自定义 UA、任意远程 INI、脚本或第三方短链。完整平台策略仍在订阅首页维护，文件名不参与选路。

每个账号最多保存 40 项，每项最多 8 个公开 HTTPS 来源、2500 个节点，展开和转换另有体积上限。客户端取用满一小时的缓存时尝试刷新。失败保留上次结果，五分钟内不重复自动尝试；管理页也可手动刷新。撤销立即停止分发，已下载到设备的副本不会被远程删除。
