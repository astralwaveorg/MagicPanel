# 用户任务与页面

## 问题与交付对象

旧版分别维护节点来源、规则资源、策略组、平台层、设备层和拓展；一个最终设置很难追到修改入口。重构以“这台设备拿到了什么配置”为入口。规则资源支持 MRS 与 YAML。旧系统保留完整运行与固定地址；新版使用自己的账号会话、设备令牌、数据、构建历史，不要求现有客户端迁移。

## 工作流与视图

| 视图 | 用户动作 | 成功标准 |
| --- | --- | --- |
| 工作台 | 登录，查看当前生效版本、草稿差异、失败位置、快速入口 | 未登录不暴露节点和设备；首屏能判断是否有未发布变更 |
| 模板 | 从已有目标复制或导入模板，选引擎、平台，编辑组顺序、基础配置和有序规则 | 同一规则可跨模板引用；显示最终规则顺序；重复名称、无效引用有明确定位 |
| 规则 | 搜索、添加、修改、删除、调整作用模板与优先级，维护规则资源 | 全局修改一次即可反映到引用处；避免把广泛规则前置而遮住专项规则 |
| 节点与来源 | 粘贴单节点或订阅，将节点纳入模板的具体组；保留来源与上次成功的快照 | 失败不覆盖好数据；节点凭据不出现在列表、日志、模型输入中 |
| 订阅地址 | 选已发布模板、引擎、线路与可选输出参数，一键复制 | 共用基础地址，无需建档；可轮换共享密钥，所有旧统一地址同时失效 |
| 发布 | 查看候选差异、校验、上线或回滚；可启用自动发布 | 同输入不重复发布；失败留在旧成功版本；旧配置资源可读 |
| 助手 | 自然语言创建规则、优化重复项、贴节点、解释配置问题 | 产生有依据且可审阅的提案；服务端重新校验后才能改草稿，无远程 shell 或生产发布权限 |

桌面端用侧栏分区与主内容区；手机改用短导航、单列卡片和全宽编辑页，表格不承担核心操作。表单有标签、清楚的保存/取消、失败后保留输入；密钥不默认回显。后台任务不阻塞普通浏览，动作结果区分“草稿已保存”“已验证”“已发布”。编辑器保留高级 YAML，但常见操作用结构化表单完成。对空列表、首次使用、权限过期、并发编辑和上游不可用提供可行动提示。
